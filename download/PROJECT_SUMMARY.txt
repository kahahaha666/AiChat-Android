# Android AI Chat App - Project Summary & Development Log

## 1. Project Goal
Build a native Android AI Chat application using Jetpack Compose, Kotlin, and Retrofit. The goal was to achieve a "one-and-done" local development environment on an Android phone, but due to compatibility issues, we shifted to a Cloud Build (GitHub Actions) approach.

## 2. Environment Challenges & Solutions

### Initial Attempt: Local Build on Phone
- **Issue**: The phone's Linux environment (Alpine) uses `musl libc`, while Android SDK tools (like AAPT2) require `glibc`.
- **Attempts**:
  - Tried installing `gcompat` and `libc6-compat`: Failed due to missing symbols (`__memcpy_chk`, etc.).
  - Tried downloading ARM64 glibc packages from Ubuntu mirrors: Network instability caused failures.
  - Tried using `proot` to run Ubuntu 22.04: Successfully downloaded `ubuntu-base` but lacked `apt/dpkg` in the minimal image.
- **Conclusion**: Local compilation of full Android APKs on Alpine Linux is extremely difficult due to binary incompatibility.

### Final Solution: Cloud Build (GitHub Actions)
- **Strategy**: Push code to GitHub and let Ubuntu runners handle the compilation.
- **Setup**:
  - Created `.github/workflows/build.yml` with JDK 17 and Gradle 8.2.
  - Generated Gradle Wrapper (`gradlew`) in the Linux environment and copied it to the project.
